# Question personas for evaluating a fitness RAG system

This repo holds personas and the questions made for them. Questions are answered separately, against the source the system uses.

## Folders

- `Project 1/`: the first set of questions.
  - `prompt.md`: the prompt given to the model, with the output format.
  - `personas/`: one file per persona.
  - `Chatgpt/`: ChatGPT's questions, one file per persona.
  - `Copilot/`: Copilot's questions, all personas in one file.
- `Project 2/`: the second set, with the new prompt in `prompt.md`.
  - `Chatgpt/` and `Copilot/`: the new results, one file per run.

## Notes

Copilot's questions in Project 1 repeat some of ChatGPT's. Nothing has been removed from the originals.
